- (decision) AD-1 Design Paradigm: MVVM with SwiftUI + @Observable. Views observe ViewModels; ViewModels own module logic and expose @Published/@Observable state.
- (decision) AD-2 UI Framework: SwiftUI with Observation framework (iOS 17+). No UIKit, no Combine.
- (decision) AD-3 Camera Capture: AVFoundation via AVCaptureSession. ProRAW for stills (iPhone 12 Pro+), Apple Log 2 for video (iPhone 15 Pro+), JPEG fallback for older devices.
- (decision) AD-4 GPU Pipeline: Metal Shading Language. Hybrid 2-pass: Pass 1 fuses LUT + halation + glow (per-pixel color transforms); Pass 2 applies grain (spatial coherence). Core Image CIColorCube used for LUT lookup within Pass 1.
- (decision) AD-5 Persistence: Minimal. Per-capture metadata (assetID, timestamp, iso, stockApplied?) stored as JSON/Codable file or lightweight SwiftData model. No database.
- (decision) AD-6 Module Boundaries: 6 modules — CameraCapture, ProcessingPipeline, FilmStockLibrary, Library, Export, Purchase. Each owns its domain; ProcessingPipeline depends on FilmStockLibrary definitions only.
- (decision) AD-7 Processing Pipeline Contract: CameraCapture produces CVPixelBuffer; ProcessingPipeline consumes CVPixelBuffer + FilmStockConfig; returns processed CVPixelBuffer. Pipeline is source-agnostic (photo or video frame).
- (decision) AD-8 Exposure State Machine: 4-mode enum — auto, shutterPriority(lockedShutter), isoPriority(lockedISO), manual(shutter, iso). Target EV always user-adjustable. Lock toggles via tap. Exposure calculation solves for unlocked parameter given locked value + target EV + metered brightness.
- (decision) AD-9 Grain Model — Photo: Single grain texture (grain.png) shared across all stocks, scaled by per-stock ISO slider. Video: 3D noise volume (128^3), each frame samples z-slice by frame index for temporal coherence with no flicker.
- (decision) AD-10 Post-Capture Flow: Two paths — auto-process (capture -> pipeline -> camera roll) or save-clean (capture -> RAW/Log to camera roll + metadata entry). In-app Library shows unprocessed captures via Photos framework asset IDs. Apply stock: pick shot -> select stock -> pipeline -> processed output to camera roll.
- (decision) AD-11 Bundled Assets: LUTs (.cube), grain texture (grain.png), 3D noise volume (grain3d.raw), and Metal shaders (.metal) ship in app bundle under Resources/. Compiled at build time.
- (decision) AD-12 ViewModels: CameraViewModel (exposure mode, capture), LibraryViewModel (capture list, post-capture apply), ProcessingViewModel (stock selection, ISO, preview), PurchaseViewModel (trial, StoreKit). Each maps 1:1 to a module.
- (decision) AD-13 Dependency Direction: CameraCapture -> nothing; FilmStockLibrary -> nothing; ProcessingPipeline -> FilmStockLibrary; Library -> FilmStockLibrary + ProcessingPipeline + Photos; Export -> ProcessingPipeline + Photos; Purchase -> nothing. No circular dependencies.
- (constraint) iOS-only v1. iPhone 12 Pro+ for ProRAW pipeline; JPEG fallback for older devices. Apple Log 2 requires iPhone 15 Pro+.
- (constraint) Seven bundled film stocks only. No custom LUT import in v1.
- (constraint) No multi-clip video editing (trim only). No combining, transitions, or audio.
- (constraint) Save to camera roll only. No in-app sharing export.
- (version) Swift 6, iOS 17+ deployment target, Xcode 16+
