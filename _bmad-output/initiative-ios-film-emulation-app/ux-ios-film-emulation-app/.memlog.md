- (decision) Design DNA: mood.camera-inspired minimalism. Maximum preview space, functional, tactile. Dark mode always.
- (decision) Camera screen: full-bleed clean preview. Record button prominent. Stock selector strip at bottom (horizontal swipe, 250D/500T). Tap stock name -> toolbar drops from top.
- (decision) Top toolbar (triggered by tapping stock name): lens selector (front/13mm/24mm/tele), flash toggle, portrait mode toggle, EV slider, gear icon.
- (decision) Shutter/ISO readouts: toggleable on/off. Locked state = blue highlight. When toggled off, only record button + stock name visible.
- (decision) Render: auto-renders after recording stops. No confirmation. Pill appears in bottom corner with progress ring + queue count number overlay. Runs in background.
- (decision) Settings (gear): trial status, purchase button, keep-original toggle, about.
- (decision) Permissions: standard iOS dialogs for camera, microphone, photos library.
- (decision) Focus: native iPhone tap-to-focus. Portrait mode toggle in toolbar.
- (decision) EV adjustment: slider in toolbar.
- (event) spines finalized: DESIGN.md (12 color tokens, typography scale, 7 components, do/donts) and EXPERIENCE.md (IA, 3 key flows, 10 state patterns, 7 interaction primitives, accessibility floor)
